### Operational-accounting-tasks


Учебные задачи по оперативному учету:

1. Задача № 1 Контроль отрицательных остатков (без складского учета).

2. Задача № 2 Учет товаров. Вариант 1 - Контроль отрицательных остатков (со складами в шапке документов).

3. Задача № 3 Учет товаров. Вариант 2 - Контроль отрицательных остатков (со складами в ТЧ документов).

4. Задача № 4 Учет товаров. Вариант 3 - Контроль отрицательных остатков (со складами и возможностью проведения документов продаж задним числом).

5. Задача № 5 Скоропортящиеся продукты. Вариант 1 - Контроль остатков.

    - При продаже списывание по FIFO, срок годности для каждого товара свой.

6. Задача № 6 Скоропортящиеся продукты. Вариант 2 - Контроль остатков.
    - При продаже во время выбора товара должна автоматически отобразиться его текущая цена.
    - При изменении количества или цены сумма по строке должна рассчитаться автоматически. 
    - При продаже товара в ТЧ предоставить возможность пользователю выбирать конкретную партию списания (срок годности), при выборе партии - ограничить выбор списком партий, которые имеются в наличии.

7. Задача № 7 Скоропортящиеся продукты. Вариант 3 - Контроль остатков.
    - Аналогично предыдущей задаче, но теперь если в партии товара меньше, чем выбрал пользователь, остальное количество должно списываться по срокам годности по FIFO.
